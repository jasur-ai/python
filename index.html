Asoslar / Foundations

O'zgaruvchilar, Turlar va Xotira Modeli

Python da o'zgaruvchi boshqa tillardan farq qiladi. U "quti" emas — "yorliq" (label). Bu farqni tushunmasangiz, keyinchalik g'alati xatolar qilasiz.

Nima uchun bu muhim?
Python da o'zgaruvchi e'lon qilishda tur (type) yozilmaydi — bu "duck typing" deyiladi. Lekin bu Python "turlarni bilmaydi" degani emas. Python ichida har bir qiymat o'zining turini biladi. Bu tushuncha xato topishda va katta loyiha yozishda juda muhim.
Xotira Modeli — O'zgaruvchi Qanday Ishlaydi
Python da x = 5 yozganingizda — "5 qiymatli ob'ekt yaratiladi, x shu ob'ektga ishora qiladi". Bu C/Java dan farqi. Shuning uchun Python da bir nechta o'zgaruvchi bir xil ob'ektga ishora qilishi mumkin.

O'rta Daraja / Functions Deep

Funksiyalar — Birinchi Darajali Ob'ekt

Python da funksiyalar — oddiy qiymat. Ularni o'zgaruvchiga saqlash, argument sifatida yuborish, qaytarib berish mumkin. Bu tushuncha dekorator, closure va callback larning asosi.

Nima uchun kerak?
Funksiyalar faqat "kod bloklari" emas. Python da funksiya birinchi darajali ob'ekt — yani boshqa funksiyaga argument sifatida beriladi, qaytariladi. Bu Decorator pattern, Callback, Middleware ning asosi. FastAPI da @app.get("/path") — bu ham dekorator!
Closure — Funksiya Ichidagi Funksiya
Closure — ichki funksiya tashqi funksiyaning o'zgaruvchilarini "eslab qoladi". Bu state saqlashning ixcham usuli.

# ─── Oddiy closure ────────────────────
def ko'paytiruvchi(n):
    def ko'paytir(x):
        return x * n    # n ni "eslab qoladi"
    return ko'paytir

ikkilat = ko'paytiruvchi(2)

# ─── Hisoblagich (counter) ─────────────
def hisoblagich_yasash():
    hisob = [0]             # list ishlatamiz (mutable)
    def hisobla():
        hisob[0] += 1
        return hisob[0]
    return hisobla

h()    # 1

h()    # 3

# Har bir hisoblagich mustaqil:
